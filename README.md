# Product Filter and Search App

A responsive e-commerce style product filtering application built with HTML, CSS, and JavaScript.

## Features
- Dynamic product rendering
- Category-based filtering
- Product search functionality
- Mobile dropdown navigation
- Responsive grid layout

## Technologies Used
- HTML5
- CSS3
- JavaScript (ES6)

## Concepts Practiced
- DOM manipulation
- Array filtering
- Event listeners
- Responsive design
- Dynamic rendering
